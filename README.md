# Lock Your Inventory

A lightweight client-side Fabric mod for Minecraft 26.2 that lets you temporarily lock keybinds without changing their assigned keys.

Press **L** by default to open the menu. Choose any Minecraft keybind and toggle it between **Active** and **Locked**. Locked keybinds stop responding until you unlock them again.

Useful for PvP when you want to temporarily disable risky or distracting controls while keeping your normal key setup intact.

## Requirements

- Minecraft 26.2
- Fabric Loader
- Fabric API
- Java 25

## Environment

Client-side only. Servers and other players do not need the mod.
